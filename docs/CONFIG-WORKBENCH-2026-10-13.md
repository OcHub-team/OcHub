## 实现

### 配置编辑

“保存到 OcHub”保存独立的 `EditorDraft`。未填完的字段、无效原文、尚未完成的键值行均可保存，不修改正式连接、当前连接身份或目标应用文件。列表提供继续编辑入口；草稿带版本检查，冲突不会覆盖新编辑。

应用会验证同一草稿版本，再准备目标配置、写入文件并提交连接记录。原始文本仍由目标 codec 解析；未建模字段保留，但不承诺所有格式的注释和空白逐字节往返。共享配置明确标出真实覆盖关系。

保存与应用成功后仍留在编辑器。写入成功只表示目标配置已写入，不宣称客户端已读取或账号已通过网络验证。Cherry Studio 的本地导入会实际调用系统 URL opener，之后显示等待目标应用确认。

侧栏、应用切换、环境切换、返回、窗口关闭和退出共用未保存修改保护。保存期间取消离开，不会在迟到回调中再次关闭编辑器。

### 插件

侧栏和连接页使用动态 `AppId` 及插件元数据。本地声明式 switch 插件可提供配置路径、文件格式、字段、条件、必填检查、模型表格和模板，并复用同一编辑器。插件目录覆盖也通过应用设置提供。

重载先验证整个候选 registry，失败保留原有插件；正在编辑的文档记录插件版本。未知远端插件可以列出和管理启用状态，但不能用本机 codec 冒充远端实现。

`audit-nova` 是仅用于隔离 QA 的测试插件，未安装到用户正式数据目录。

### 写入、撤销与恢复

普通配置应用使用文件准备计划、文件指纹检查、私有恢复日志和数据库事务。多文件写入不是文件系统级整体原子操作；发生失败时进行补偿，无法证明可恢复的状态明确保留待恢复结果。

撤销仅在有完整回执且目标文件与数据库仍匹配时开放。外部编辑或更新的连接记录会阻止撤销，避免覆盖用户的新变化。撤销后读取真正恢复的草稿版本，再继续编辑。官方凭据、网关运行状态及外部应用确认等无法完整逆转的副作用不提供虚假的一键撤销。

启动时尝试恢复可证明的未完成提交。恢复失败暂停自动配置写入并给出提示，仍保留诊断能力。旧 Application/ProviderService 常规写入入口复用协调器；声明文件内的每个配置资源受保护，但不承诺整份批量声明是一个事务。

### 远程

以附加的 `editor-drafts-v1` feature 协商草稿能力，旧握手中没有此字段也能解析。旧节点禁用保存和应用，明确提示升级。草稿保存、应用与撤销沿用远程权限和幂等机制。

保存确认不在重试缓存中复制任意草稿原文。应用缓存仅保存结果元数据；重放所需的完整连接来自已有的私有应用回执。默认 CLI 输出不暴露原始草稿或配置正文。

应用回包丢失时，编辑器明确显示结果尚未确认，保留新输入并暂停继续保存。重新连接同一节点后，“核对上次应用”直接核对原草稿 ID 与 revision，不先保存覆盖该版本。离开提示说明离开不会取消可能已完成的远端操作。

### 通知视觉与使用方式

用户补充反馈 toast 过于抢眼后，由两名子代理再次设计、实现与交叉复核。通知改为至多 350px 的中性面板、细边框、小状态图标和正常字重，移除整块语义色背景、图标色块及进度装饰。长文本换行并限高滚动，复制和关闭留在滚动区外；鼠标悬停或键盘聚焦时暂停自动消失。

同步配置检查和原文回填使用编辑器内的结果说明，不再重复弹 toast。异步任务和全局操作继续使用统一通知。

共享 UI 库提交为 `4c1ae8176bde4288dfc1aa5c175e4ffcd81a5c95`，主仓库使用该 Git revision；没有改为本机路径依赖。UI 库 109 项测试通过，其中通知专项 14 项通过。
