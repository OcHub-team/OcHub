## macOS 输入快捷键

原有 Cmd+A/C/V/X/Z 绑定已经存在。修复补齐 Option 单词移动/删除、Cmd 行/文档导航、Shift 扩选、Ctrl+A/E/B/F/P/N/H/D/K/Y，并把编辑绑定限制到对应输入上下文，防止查找框误操作外层代码。Windows/Linux 同步补齐 Ctrl 单词导航/删除及 Home/End 扩选。

代码编辑器同时修正 IME 相对 UTF-16 偏移、撤销后的 UTF-8 边界和反向选择。单行输入与代码编辑器共有 32 项回归；其中 12 项覆盖本轮新增行为。最终复核另外修正了显式 FocusHandle 的 Tab 属性、查找工具栏的按钮遍历，以及多行扩选时活动端的滚动跟随。原生 macOS 已验证 Option+Backspace、Cmd+A、粘贴包含中文/emoji 的文本、Cmd+Z、Ctrl+A/K/Y。没有将合成键盘输入等同于所有真实中文输入法组合的验收。

## 应用与插件控件

管理页使用紧凑行：应用名称、内置适配/用户插件来源、管理状态，以及“启用管理/停用管理”小按钮。保留忙碌状态、最后一个应用的禁用原因和键盘/AX 语义。插件目录和重新加载采用小按钮组。

Codex 实际生效的会话偏好使用左侧复选框。Claude 的 `enableClaudePluginIntegration`、`skipClaudeOnboarding` 没有业务读取方，因此移除这两个空操作控件，保留历史设置字段以兼容已有文件。高级工具中独立存在的实际动作不受影响。

当前未知 AppId 仍不能贯通桌面连接页。界面明确提示“CLI 可用 · 暂无桌面页面”。这轮修复没有完成“新增受管应用只安装插件，无需改主程序”的架构目标，也没有虚构安装、版本或卸载功能；剩余设计见 [Config 与插件化审计](CONFIG-PLUGIN-AUDIT-2026-10-13.md)。

## Windows/Linux

按实际平台标题栏高度计算内容区，macOS 流量灯/拖动区只在 macOS 使用。Linux 客户端装饰补齐八方向缩放命中区、最大化/贴边约束和窗口按钮语义；服务端装饰不重复扣除标题栏。非 macOS 使用系统 UI 字体，等宽字体从实际可用字体中选择。

Linux/FreeBSD 的模糊背景在目前没有 compositor 能力查询的实现下回退为不透明背景；显式透明模式保留。Windows/macOS 原生模糊仍保留。

平台判断与相关 render 分支已纳入测试，但本机只有 macOS。没有 Windows DPI、多屏幕缩放或 Linux GNOME/KDE/Wayland/X11 的真实截图与操作结果，不能据此宣布客户环境问题全部解决。
