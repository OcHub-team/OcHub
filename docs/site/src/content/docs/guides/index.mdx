## Continue by app

The provider workflow is shared, but authentication, file formats, and advanced
capabilities differ:

| Tool | Guide | Focus |
| --- | --- | --- |
| Claude Code / Claude Desktop | [Configure Claude](/guides/claude) | Auth variables, role models, plugins, and MCP |
| Codex | [Configure Codex](/guides/codex) | OAuth, Responses, reasoning, and history |
| Grok Build | [Configure other tools](/guides/open-tools#grok-build) | Profiles, API backends, and environment variables |
| OpenCode | [Configure other tools](/guides/open-tools#opencode) | AI SDK, multiple providers, and OMO |
| OpenClaw | [Configure other tools](/guides/open-tools#openclaw) | API protocols, default model, and tool permissions |
| Hermes | [Configure other tools](/guides/open-tools#hermes) | API modes, models, and memory |

When moving existing data from cc-switch, start with the
[migration guide](/guides/migration) for ID-collision, backup, and staged
verification guidance.

For model routing, database restoration, or app-specific JSON, continue to
[Advanced features](/advanced).
