<Aside type="note" title="What sponsorship does and does not mean">

These are paid third-party services, not part of OcHub. The provider manages
your account, billing, and API key. OcHub does not proxy or resell their service
and is not involved in the transaction. You can use any other provider exactly
as before.

</Aside>

## Becoming a sponsor

Sponsorship helps fund OcHub's development and keeps it free and
[GPL-3.0 licensed](https://github.com/OcHub-team/OcHub/blob/main/LICENSE). If
you run a service that OcHub users would benefit from, open an issue on
[GitHub](https://github.com/OcHub-team/OcHub/issues) to start a conversation.
