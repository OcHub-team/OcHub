## Routes and endpoints

### Krill

The three routes are equivalent: pick one, or fill in all of them as a failover
set on a model provider.

| Route | Claude Code / Claude Desktop | Codex |
| --- | --- | --- |
| Primary | `https://api.krill-ai.net` | `https://api.krill-ai.net/v1` |
| CDN | `https://api.cdn-krill-ai.com` | `https://api.cdn-krill-ai.com/v1` |

## Connect a sponsor endpoint

Both providers serve the Anthropic Messages API and an OpenAI-compatible API on
the same origin. Anthropic-dialect clients take the bare origin and append
`/v1/messages` themselves; OpenAI-dialect clients take the origin plus `/v1`.
The tables above already show both forms, and OcHub picks the right one for
you.

<Steps>

1. Open OcHub, pick your tool, and add a connection.

2. Under **Sponsor endpoints**, click a card. The endpoint is filled in, and
   for Krill you can switch route without retyping anything.

3. Paste the API key you obtained from the sponsor's own site, then test and
   save.

</Steps>

**Model providers** work the same way: clicking a sponsor there fills in the
name, website and every route it serves — Krill's three routes go in together
as a failover set.


<Aside type="note" title="What sponsorship does and does not mean">

These are paid third-party services, not part of OcHub. OcHub only pre-fills
the endpoint: your account, billing and API key live with the provider, and
your requests go straight from your machine to them. OcHub does not proxy,
resell, or see that traffic. You can use any other provider exactly as before.

</Aside>
