OcHub は GPUI と axum を中心に構築された Rust ワークスペースです。

## クレート構成

| クレート | 役割 |
| --- | --- |
| `ochub-core` | ドメインモデル、SQLite ストレージ、プロバイダー切り替え、クライアント設定の書き込み、同期、MCP、スキル、セッション、使用量、認証 |
| `ochub-server` | ループバック制御 API とプロセス内リレーゲートウェイ |
| `ochub-convert` | 対応 API 方言間のリクエスト・レスポンス変換 |
| `ochub-app` | core と server をホストする GPUI ネイティブデスクトップアプリケーション |

## プラットフォーム固有の事情

GPUI はテスト済みの Zed コミットに固定されています。Linux ビルドは Wayland と X11 の
両方を有効にし、macOS ビルドは実行時に Metal シェーダーをコンパイルします。
