OcHub はアプリごとに接続を分けて保存します。Claude Code の接続が
Codex に自動で現れることはありませんが、**アプリへコピー**で対象形式の新しい設定を
生成できます。

## 既存設定を検出する

アプリページを開くと、OcHub はツールの現在の実設定を読み取ります。

- 認識できる接続は「直接接続」に表示されます。
- ツールに存在するが現在ではない項目は「追加済み」と表示されます。
- 使用中の接続は「現在」と表示されます。
- フォームで完全に表現できないカスタム項目は、保存前に書き込みプレビューを確認します。

## 日常の操作

| 操作 | 用途 |
| --- | --- |
| 編集 | アドレス、キー、モデル、メモ、高度な項目を変更 |
| ドラッグで並べ替え | リストとシステムメニューの表示順を変更 |
| アプリへコピー | 対象アプリ形式で新しい接続として保存 |
| ツールに追加 | 現在の接続を変えずに事前登録 |
| 切り替え | 直ちに現在の接続に設定 |
| ツールから削除 | OcHub データを残し、実設定だけから削除 |
| 削除 | OcHub から完全に削除 |

現在使用中の接続を削除する前に、別の接続へ切り替えます。

## 公式ログイン

**公式ログインを使用**はサードパーティーの Base URL や API キーを書き込まず、
ツール自身のログイン状態を利用します。

- Claude Code または Codex ですでに公式アカウントへログイン済み。
- サードパーティー API から一時的に公式サービスへ戻す。
- ツール固有のアカウントやサブスクリプション機能を維持する。

Codex の「サードパーティーで現在の OAuth を保持」を有効にすると、切り替え時に
`auth.json` を上書きしません。この設定は Codex だけに作用します。

## アプリ固有設定

アプリページ右上の**アプリ設定**を開きます。

| アプリ | 主な設定 |
| --- | --- |
| Claude Code | MCP オンボーディングのスキップ、Claude プラグイン連携、カスタム設定ディレクトリ |
| Codex | OAuth 保持、履歴統合、既存セッション移行、カスタム設定ディレクトリ |
| OpenCode | カスタム設定ディレクトリ |
| OpenClaw | カスタム設定ディレクトリ |
| Hermes | カスタム設定ディレクトリ |
| Grok Build | カスタム設定ディレクトリ |

カスタムディレクトリは、設定、MCP、セッション履歴の読み取り先を変更します。保存後に
OcHub と対象ツールを再起動してください。

## エディター内のチェック

- **URL をテスト**：HTTP 応答のレイテンシーを測定。
- **モデルを取得**：現在のアドレスとキーでモデル一覧を取得。
- **残高を確認**：互換する残高 API がある上流サービスのみ。
- **書き込むファイル**：生成内容と保存先を表示。
- **共通設定**：アプリ単位の共有スニペットを有効な接続へマージ。

テスト成功はモデル呼び出しの成功を保証しません。最終確認は対象 CLI の実リクエストです。

## 外部で設定が変更された場合

OcHub は書き込み前に設定ドリフトを確認します。競合がある場合：

1. 「保持する」「削除状態を維持」「同時に保持できない」を確認します。
2. 外部項目が必要なら**自分の変更を保持**を選びます。
3. OcHub のプレビューを優先するなら**自分の変更を破棄**を選びます。
4. 判断できなければキャンセルし、バックアップして比較します。

OcHub、cc-switch、手動エディターで同じファイルを同時に編集しないでください。

## 新しい接続を確認する

任意のアプリで接続を保存または切り替えた後：

1. 生成ファイルとパスを確認。
2. 保存後に「追加済み」または「現在」を確認。
3. 対象ツールを完全に再起動。
4. 新しいプロバイダーとモデルを選択。
5. 短いリクエストを送信。
6. ツールエラー、OcHub 使用量、上流ログを確認。

| 問題 | よくある原因 |
| --- | --- |
| 接続がない | 保存だけで追加していない、またはディレクトリ違い |
| 別項目を上書き | 共存アプリで Provider ID が重複 |
| 401 | キー、環境変数、起動環境の不一致 |
| 404 / ボディエラー | バックエンド、プロトコル、API モードの誤り |
| モデルは見えるが失敗 | ID、コンテキスト、権限の不一致 |
| 高度な保存に失敗 | JSON/YAML ノード型の誤り |
