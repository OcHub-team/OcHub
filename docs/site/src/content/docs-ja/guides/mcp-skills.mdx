MCP サーバーとスキルは複数アプリへ配布できますが、同期方法が異なります。

- MCP は OcHub が JSON を保存し、有効なアプリへ書き込みます。
- スキルは skills CLI がインストールし、カードのアプリ別トグルで配布先を決めます。

## 対応アプリ

| アプリ | MCP | スキル |
| --- | --- | --- |
| Claude Code | 対応 | 対応 |
| Claude Desktop | 非対応 | 非対応 |
| Codex | 対応 | 対応 |
| Grok Build | 対応 | 非対応 |
| OpenCode | 対応 | 対応 |
| OpenClaw | 非対応 | 非対応 |
| Hermes | 対応 | 対応 |

トグルは実際に対応する機能だけに表示されます。Claude Desktop と OpenClaw のネイティブ
拡張は、これらのページでは管理しません。

## 既存 MCP をインポートする

<Steps>

1. **MCP サーバー**を開きます。
2. **アプリからインポート**を選びます。
3. 対応アプリをスキャンし、共有ストアにまだないサーバーだけを追加します。
4. 各カードのアプリ一覧を確認し、**アプリへ同期**を選びます。

</Steps>

インポートはアプリ内の未知の設定を自動削除しません。一部失敗した場合は対象が表示されます。

## MCP を手動追加する

**追加**を選び、名前、任意の説明、サーバー JSON を入力します。

stdio の例：

```json
{
  "type": "stdio",
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem"]
}
```

SSE の例：

```json
{
  "type": "sse",
  "url": "https://example.com/sse"
}
```

保存前に少なくとも 1 つの対象アプリを選びます。JSON はオブジェクトである必要があります。
コマンド、引数、環境変数などは各ツールの形式へ変換されます。

stdio MCP は `command` をローカルで実行します。信頼できるパッケージだけを同期し、
対象ツールから見える `PATH` にコマンドがあることを確認してください。

</Aside>

## MCP を有効化して同期する

1. サーバーカードでアプリを有効または無効にします。
2. 複数変更した後に**アプリへ同期**を選びます。
3. 対象 CLI を再起動します。
4. 表示されない場合、アプリの有効状態、設定ディレクトリ、対応する転送方式を確認します。

<OcHubStepsVisual
  locale="ja"

OcHub から MCP を削除した後は、もう一度同期して管理対象の実設定を更新します。削除は
元に戻せないため、必要なら JSON をコピーしておきます。

## マーケットからスキルをインストールする

<Steps>

1. **スキル → 探す**でマーケット検索を選びます。
2. `pdf`、`frontend`、`testing` などの用途で検索します。
3. インストール先アプリを選びます。
4. カードの**インストール**を選びます。
5. 「インストール済み」でスキルと提供元を確認します。

</Steps>

## リポジトリから探す

1. 「探す」をリポジトリブラウザーへ切り替えます。
2. `owner/repo`、`owner/repo@branch`、または GitHub URL を入力します。
3. 追加後に**検出を更新**します。
4. 結果から必要なスキルをインストールします。

リポジトリを無効化すると検出から外れますが、既存スキルは削除されません。リポジトリの
削除もスキルのアンインストールにはなりません。

## 更新と配布

- **更新を確認**でローカルとリモートのバージョンを比較します。
- 個別更新または**すべて更新**を使用します。
- アプリ別トグルで配布先を決めます。
- **ディレクトリ**はローカル、**リポジトリ**は提供元を開きます。
- アンインストールは skills CLI を通して有効なアプリから削除します。

検索と更新にはネットワークが必要です。skills CLI が使えない場合は
[高度な機能](/ja/advanced)でインストールと `PATH` を確認してください。

Claude プラグイン、Codex ディレクトリ、OpenCode / Hermes の違いは
[Claude ガイド](/ja/guides/claude)、[Codex ガイド](/ja/guides/codex)、
[その他のツール](/ja/guides/open-tools)を参照してください。
