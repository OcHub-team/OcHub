## 特定のツールを設定する

接続の操作は共通ですが、書き込み方式、認証、高度な機能は異なります。各ツールに専用の
ガイドグループがあります。

| ツール | ガイド | 書き込み方式 | MCP | スキル |
| --- | --- | --- | --- | --- |
| Claude Code | [Claude を設定する](/ja/claude) | 現在の接続を切り替え | 対応 | 対応 |
| Claude Desktop | [Claude を設定する](/ja/claude) | 現在の接続を切り替え | 非対応 | 非対応 |
| Codex | [Codex を設定する](/ja/codex) | 現在の接続を切り替え | 対応 | 対応 |
| Grok Build | [Grok Build を設定する](/ja/grok-build) | 現在の接続を切り替え | 対応 | 非対応 |
| OpenCode | [OpenCode を設定する](/ja/opencode) | 複数接続の共存 | 対応 | 対応 |
| OpenClaw | [OpenClaw を設定する](/ja/openclaw) | 複数接続の共存 | 非対応 | 非対応 |
| Hermes | [Hermes を設定する](/ja/hermes) | 複数接続の共存 | 対応 | 対応 |

「現在の接続を切り替え」方式では、ツールの実設定が 1 つの有効な接続を指します。共存方式では、
OcHub が複数の接続を 1 つのツール設定へ書き込み、「ツールから削除」はその項目だけを削除します。

cc-switch から既存データを移す場合は、ID 競合、バックアップ、段階的な確認を説明する
[移行ガイド](/ja/guides/migration)から始めます。

モデルルーティング、データベース復元、アプリ固有 JSON は
[高度な機能](/ja/advanced)へ進んでください。
