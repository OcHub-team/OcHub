## アプリ別ガイド

基本的な接続の操作は共通ですが、認証、ファイル形式、高度な機能が異なります。

| ツール | ガイド | 主な内容 |
| --- | --- | --- |
| Claude Code / Claude Desktop | [Claude を設定](/ja/guides/claude) | 認証変数、役割モデル、プラグイン、MCP |
| Codex | [Codex を設定](/ja/guides/codex) | OAuth、Responses、推論、履歴 |
| Grok Build | [その他のツール](/ja/guides/open-tools#grok-build) | プロファイル、API バックエンド、環境変数 |
| OpenCode | [その他のツール](/ja/guides/open-tools#opencode) | AI SDK、複数接続、OMO |
| OpenClaw | [その他のツール](/ja/guides/open-tools#openclaw) | API プロトコル、デフォルトモデル、ツール権限 |
| Hermes | [その他のツール](/ja/guides/open-tools#hermes) | API モード、モデル、メモリ |

cc-switch から既存データを移す場合は、ID 競合、バックアップ、段階的な確認を説明する
[移行ガイド](/ja/guides/migration)から始めます。

モデルルーティング、データベース復元、アプリ固有 JSON は
[高度な機能](/ja/advanced)へ進んでください。
