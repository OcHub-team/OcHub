OcHub は AI コーディングツールのためのネイティブデスクトップ管理センターです。
モデルプロバイダーの切り替え、共有機能の管理、ローカルゲートウェイの実行を一か所でまとめて行えます。
ブラウザシェルも WebView も必要ありません。

## OcHub が管理するもの

OcHub は **Claude Code、Claude Desktop、Codex、Grok Build、OpenCode、OpenClaw、Hermes**
を管理します。

| 領域 | 機能 |
| --- | --- |
| 接続 | 直接 API 接続の検出、インポート、編集、切り替え、テスト |
| モデルプロバイダー | 対応クライアントをローカルゲートウェイ経由でルーティング。モデルエイリアス、推論マッピング、インターフェース候補の再試行、予備のモデルプロバイダー切り替え、ヘルスチェック、使用量集計に対応 |
| 共有ツール | 対応クライアント間で MCP サーバーと再利用可能なスキルを管理 |
| 運用 | セッションの閲覧、使用量の確認、同期の設定、アプリ動作の管理 |
| 移行 | 互換性のある cc-switch データベースからの一度きりの読み取り専用インポート |

## 設定への影響範囲

OcHub は `~/.ochub/` を所有し、`~/.cc-switch/` へ書き戻すことはありません。
ただし、明示的に管理対象としたツールの実設定ディレクトリは更新します。

:::caution
OcHub で接続を切り替える前に cc-switch を終了してください。両者は同じツール設定
ディレクトリに書き込むため、同時に実行すると書き込みが交錯するおそれがあります。
:::

:::note
OcHub はプレリリース段階で活発に開発中です。早期ビルドを試す前に、重要なツール設定を
バックアップしてください。
:::
