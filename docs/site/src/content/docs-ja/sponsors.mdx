<Aside type="note" title="スポンサーシップが意味すること・しないこと">

これらは有料の第三者サービスであり、OcHub の一部ではありません。アカウント、請求、
API キーはプロバイダー側が管理します。OcHub がサービスを中継・再販したり、取引に
関与したりすることはありません。これまでどおり他のプロバイダーも自由に使えます。

</Aside>

## スポンサーになるには

スポンサーシップは OcHub の開発を支え、無料かつ
[GPL-3.0 ライセンス](https://github.com/OcHub-team/OcHub/blob/main/LICENSE)で
あり続けることを可能にします。OcHub のユーザーに役立つサービスを運営している
方は、[GitHub](https://github.com/OcHub-team/OcHub/issues) で issue を立てて
ご相談ください。
