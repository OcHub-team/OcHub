## 回線とエンドポイント

### Krill

3 本の回線は等価です。1 本だけ使っても、モデルプロバイダーにまとめて登録して
フェイルオーバーの組にしても構いません。

| 回線 | Claude Code / Claude Desktop | Codex |
| --- | --- | --- |
| メイン回線 | `https://api.krill-ai.net` | `https://api.krill-ai.net/v1` |
| CDN 回線 | `https://api.cdn-krill-ai.com` | `https://api.cdn-krill-ai.com/v1` |
| ロードバランス | `https://api-slb.krill-ai.net` | `https://api-slb.krill-ai.net/v1` |

### 合租巴士 (Hezu Bus)

API ドメインが公式サイトと同一のため、回線は 1 本のみです。

| 回線 | Claude Code / Claude Desktop | Codex |
| --- | --- | --- |
| メイン回線 | `https://hezubus.cc` | `https://hezubus.cc/v1` |

## スポンサー回線に接続する

どちらも同じオリジンで Anthropic Messages API と OpenAI 互換 API の両方を提供して
います。Anthropic 方言のクライアントはオリジンをそのまま受け取り `/v1/messages`
を自分で付けます。OpenAI 方言のクライアントはオリジンに `/v1` を付けたものを
使います。上の表には両方の形式を載せてあり、OcHub が適切な方を選びます。

<Steps>

1. OcHub を開き、設定したいツールを選んで接続を追加します。

2. **スポンサー回線**でカードをクリックすると、エンドポイントが入力されます。
   Krill では入力し直すことなく回線を切り替えられます。

3. プロバイダーの公式サイトで取得した API キーを貼り付け、テストして保存します。

</Steps>

**モデルプロバイダー**でも同様です。スポンサーをクリックすると名称・公式サイトと
提供中のすべての回線が一度に入力され、Krill の 3 本はそのままフェイルオーバーの
組になります。


<Aside type="note" title="スポンサーシップが意味すること・しないこと">

これらは有料の第三者サービスであり、OcHub の一部ではありません。OcHub が行うのは
エンドポイントの事前入力だけです。アカウント、請求、API キーはプロバイダー側に
あり、リクエストはあなたのマシンから直接そこへ送られます。OcHub が中継したり、
再販したり、その通信を見たりすることはありません。これまでどおり他のプロバイダー
も自由に使えます。

</Aside>

## スポンサーになるには

スポンサーシップは OcHub の開発を支え、無料かつ
[GPL-3.0 ライセンス](https://github.com/OcHub-team/OcHub/blob/main/LICENSE)で
あり続けることを可能にします。OcHub のユーザーに役立つサービスを運営している
方は、[GitHub](https://github.com/OcHub-team/OcHub/issues) で issue を立てて
ご相談ください。
