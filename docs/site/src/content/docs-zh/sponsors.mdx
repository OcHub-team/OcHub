## 连接赞助商线路

两家都在同一个地址上同时提供 Anthropic Messages 接口和 OpenAI 兼容接口。
Anthropic 方言的客户端拿裸地址、自己拼 `/v1/messages`；OpenAI 方言的客户端则要
在地址后面加 `/v1`。上面的表格两种都列了，而 OcHub 会自动替你选对。

<Steps>

1. 打开 OcHub，选择你要配置的工具，新建一条连接。

2. 在**赞助商线路**里点击一张卡片，接口地址就填好了；Krill 还可以直接切换线路，
   不用重新输入任何东西。

3. 粘贴你在对方官网获取的 API Key，测试后保存。

</Steps>

也可以走**模型供应商**：在那里点击赞助商，会一次填好名称、官网与它的全部线路
——Krill 的三条线路会直接成为一组故障转移地址。



<Aside type="note" title="赞助意味着什么、不意味着什么">

它们是付费的第三方服务，不属于 OcHub。OcHub 只负责预填接口地址：你的账号、
账单和 API Key 都在对方那里，请求也是从你的机器直接发给它们的。OcHub 不做代理、
不做转售，也看不到这些流量。你完全可以照旧使用任何其他供应商。

</Aside>
