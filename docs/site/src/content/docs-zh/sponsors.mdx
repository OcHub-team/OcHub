<Aside type="note" title="赞助意味着什么、不意味着什么">

它们是付费的第三方服务，不属于 OcHub。你的账号、账单和 API Key 都由对方管理。
OcHub 不做代理或转售，也不参与双方的交易。你仍然可以自由使用任何其他供应商。

</Aside>

## 成为赞助商

赞助会用于 OcHub 的开发，让它保持免费并采用
[GPL-3.0 许可](https://github.com/OcHub-team/OcHub/blob/main/LICENSE)。如果你
运营的服务对 OcHub 用户有价值，欢迎到
[GitHub](https://github.com/OcHub-team/OcHub/issues) 开 issue 聊聊。
