高级功能会直接影响路由、历史记录或工具配置。动手前先完成一条普通连接，并确认能发起真实
请求；这样出现问题时可以快速切回已知可用状态。

## 自动路由与接口转换

一个转发站可以同时启用以下接口：

- Anthropic Messages
- OpenAI Chat
- OpenAI Responses

自动路由会优先选择客户端原生接口；模型在该接口不可用或接口故障时，再尝试其他已启用
接口。至少保留一个接口。自动检测只是起点，上游文档明确限制接口时应手动调整。

## 默认模型

填写默认模型后，客户端请求的模型没有命中例外规则时，OcHub 会改用默认模型。适合只有
一个可用模型的上游。

不要为了“保险”随意填写默认模型：它会掩盖客户端传错模型名的问题，也可能让不同用途的
请求全部落到同一个模型。

## 模型例外

只有自动路由无法表达的情况才需要添加例外。每条规则包含：

| 字段 | 作用 |
| --- | --- |
| 模型或模式 | 匹配客户端传入的模型，可使用页面支持的通配模式 |
| 指定接口 | 强制使用某个已启用接口，或继续自动选择 |
| 转发站模型名 | 把客户端模型改写为上游模型；留空则保持原名 |

先写最具体的规则，并用真实请求验证。规则指定的接口必须保持启用。

模型规则的完整优先级和常见配置实例见[转发站路由实战](/zh/advanced/routing-recipes)。

## 思考强度

转发站提供三种处理方式：

- **自动映射**：在不同 CLI 的强度档位与上游 Token 预算之间转换。
- **原样传递**：不改写客户端提供的思考参数。
- **关闭思考**：移除或关闭相关参数。

自动映射可配置低、中、高、最大四档预算。四个值必须是递增的正整数。上游只支持强度枚举
而不支持 Token 预算时，应以它的接口文档为准。

## 快速切换与备用上游

转发站应用到工具后，供应商页面可以直接切换当前上游。此后切换只更新本地路由，不重新
写入工具配置。

建议保留一个已验证的备用上游。主站异常时：

1. 在应用页面切换到备用转发站。
2. 发起一条短请求。
3. 在用量日志中比较状态和延迟。
4. 主站恢复后再切回，不要在故障期间同时修改模型规则。

自动路由会在同一转发站已启用的接口间选择和重试；主站与备用站之间仍需手动切换。

## 用量与计费

请求可以正常返回但成本仍为 0，通常是计价模型没有匹配价格。先从请求详情记录“请求模型”
“模型”和“计价模型”，再配置每百万 Token 的输入、输出、缓存读写价格。

Claude 与 Codex 还可以设置默认成本倍率和计价模型来源。经过模型别名或路由改写时，重点
核对计价模型是否代表供应商实际收费模型。完整校准流程见
[模型定价与成本校准](/zh/advanced/pricing)。

## 供应商高级编辑

### 通用配置

“通用配置”是按应用共享的配置片段。打开“应用通用配置到此供应商”后，OcHub 写入工具
配置时会合并该片段。

从当前配置提取前先确认文件中没有只属于某个供应商的密钥或模型，否则会错误地扩散到其他
供应商。

### 原始文件编辑

在“将写入的文件”中选择“编辑”，可以直接修改生成内容。应用后，OcHub 会尝试把改动同步
回上方表单。

只有表单无法表达某个受支持字段时才使用原始编辑。保存前刷新预览，确认自定义字段仍在。

## CLI 工具维护

打开**高级工具**：

1. 点击“刷新版本”查看各 CLI 的本地版本、最新版本和环境来源。
2. 点击“扫描安装位置”检查 PATH 默认项、重复安装和异常可执行文件。
3. 缺少工具时使用“安装缺失工具”。
4. “更新全部工具”会执行对应更新命令；先阅读页面显示的命令与是否需要确认。

多个包管理器同时安装同一 CLI 时，先决定保留哪个来源，再手动整理 PATH。OcHub 会报告
冲突，但不会替你删除未知安装。

## 环境变量冲突

“环境变量冲突”会按应用扫描可能覆盖配置文件的变量。选择“删除并备份”前：

1. 核对变量名和目标应用。
2. 记录备份路径。
3. 处理后重启终端和目标 CLI。
4. 需要撤回时使用“恢复备份”并提供原备份路径。

环境变量常由 shell 配置、启动器或公司设备策略注入；删除后再次出现时，应继续检查真实
来源。

## 工具专属项目

| 工具 | 高级能力 |
| --- | --- |
| Codex | 检查统一历史备份、恢复官方历史 |
| Claude | 跳过或恢复引导、应用或恢复 OcHub 插件、读取和校验 MCP |
| OpenCode | 读取并禁用 OMO / OMO Slim 配置 |
| OpenClaw | 检查配置，编辑默认模型、环境变量和工具 JSON |
| Hermes | 编辑模型 JSON、MEMORY 与 USER 记忆及其启用状态 |

这些操作可能覆盖文件，但 OpenClaw、Hermes 和环境变量操作会在可用时生成备份。状态提示中
出现备份路径时立即保存下来。

数据恢复和远端同步请阅读[数据、备份与同步](/zh/advanced/data-sync)；需要从 cc-switch
搬迁时阅读[从 cc-switch 迁移](/zh/guides/migration)。
