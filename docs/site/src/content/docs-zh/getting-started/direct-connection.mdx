直接连接会把连接配置写入指定 AI 工具，由该工具直接请求上游供应商，不经过 OcHub
本地网关。这是最适合第一次上手的方式。

<OcHubAppFigure locale="zh" screen="editor" />

## 什么时候使用直接连接

- 第一次配置 OcHub。
- 一个工具只需要直接请求一个供应商地址。
- 希望继续使用工具自身的官方账号登录。

如果多个工具需要共用路由、模型别名或备用上游，请改用
[模型供应商](/zh/getting-started/relay)。

## 新增连接

<Steps>

1. **选择应用。** 从左侧“应用”分组打开要配置的工具。

2. **打开编辑器。** 点击“添加连接”。如果页面已经自动识别出本机配置，可以先编辑识别结果，不必重复创建。

3. **选择起点。** 有合适预设时先选预设；否则从空白配置开始。填写一个能区分用途的名称，例如“工作账号”或“备用节点”。

4. **填写连接信息。** 输入供应商要求的 API 地址和密钥。地址按供应商文档填写；模型供应商编辑器会自动处理 `/v1`，直接连接编辑器则以页面生成的文件预览为准。

5. **检查连接。** 可用时依次执行“测试 URL”“拉取模型”或“查询余额”。测速成功只说明地址能返回 HTTP 响应，不等于密钥和模型一定有效。

6. **检查写入预览。** 展开“将写入的文件”，确认目标路径和关键字段。预览为空时，先补齐名称和连接信息。

7. **保存。** 保存只把连接加入 OcHub；是否立即写入目标工具，取决于当前页面提供的操作。

</Steps>

## 添加与切换

连接卡片可能显示以下操作：

| 操作 | 含义 |
| --- | --- |
| 添加到工具 | 把连接加入工具配置，但不一定把它设为当前项 |
| 切换 | 写入或选择该连接，并把它设为当前项 |
| 从工具移除 | 从工具配置移除该项，OcHub 中保存的连接仍然存在 |
| 删除 | 从 OcHub 删除连接；这是不可撤销操作 |

切换成功后，页面顶部“当前连接”会显示新的连接，并在卡片上标记“当前”。

## 验证是否生效

1. 退出并重新打开目标 CLI，避免旧进程继续使用缓存配置。
2. 发起一条短请求。
3. 如果请求成功，再回到 OcHub 的**用量**页面刷新，确认是否出现会话或请求记录。
4. 如果工具仍使用旧配置，检查应用设置中的配置目录是否与实际安装一致。

## 处理外部修改

如果目标配置在 OcHub 之外被改动，切换时会出现“配置文件已被外部修改”：

- **保留我的修改**：尽量合并文件中的外部改动；无法安全合并的字段会单独列出。
- **丢弃我的修改**：以 OcHub 即将写入的配置为准。
- **取消**：不写入文件，先手动备份和比较。

不确定时选择“取消”。先复制原文件，再重新执行切换。

## 撤回

- 要换回其他连接，直接在同一应用页面点击其“切换”。
- 要恢复工具自身的登录状态，切换到“官方登录”连接。
- 要完全停止 OcHub 管理该工具，可在**设置 → 应用与插件**中停用它；停用不会主动改写当前工具配置。
