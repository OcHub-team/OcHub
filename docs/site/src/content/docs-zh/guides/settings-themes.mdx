设备级选项集中在“设置”，界面配色集中在“主题”。应用页右上角的“应用设置”只影响
当前 AI 工具，不要和设备级设置混淆。

## 通用设置

| 设置 | 作用 |
| --- | --- |
| 语言 | 跟随系统，或固定为受支持语言 |
| 首选终端 | 打开会话时使用的终端；“自动”会探测本机环境 |
| 开机启动 | 登录系统后启动 OcHub |
| 启动时不显示窗口 | 仅在开机启动开启时生效 |
| 关闭窗口后继续运行 | 关闭主窗口但保留后台进程 |
| 系统菜单快捷切换 | 在 macOS 顶栏或 Windows 任务栏显示连接入口 |

如果选择静默启动，同时又关闭后台运行和系统菜单，重新打开主窗口会变得不方便。调整启动
行为后，至少保留一种可见入口。

## 管理应用与插件

打开**设置 → 应用与插件**：

- 开关控制应用是否出现在侧栏和系统菜单中。
- 至少要保留一个启用的应用。
- 停用不会删除连接数据，也不会改写该工具当前配置。
- 用户插件从 `~/.ochub/apps/*.toml` 加载。
- 修改 manifest 后点击“重新加载插件”，加载错误会在同一页面列出。

## 切换主题

1. 打开**主题**。
2. 选择“跟随系统”“固定浅色”或“固定深色”。
3. 在主题库中点击“应用”。
4. 跟随系统时，OcHub 会在同一主题的浅色和深色变体之间切换。

## 导入、导出与编辑

- 内置主题只读；点击“复制并编辑”创建用户副本。
- 用户主题可以编辑名称、作者、说明、材质、透明度和颜色令牌。
- “更新预览”会临时把整个应用切换到草稿；保存或取消后退出预览。
- 浅色与深色变体必须分别配置，并通过文字、强调色和表面的可读性校验。
- “导出”用于分享主题文件，“导入主题”会校验两个变体后再加入主题库。

编辑颜色时使用完整的 `#RRGGBB`。如果保存提示对比度不足，根据错误中列出的变体和字段
调整前景或背景，直到至少达到 4.5:1。

## 恢复

- 主题预览不满意时点击“取消”，应用会回到预览前的主题。
- 内置主题不能删除。
- 删除用户主题会移除本机主题文件，属于不可撤销操作；需要保留时先导出。
