## 配置特定工具

通用连接流程相同，但写入模式、鉴权和高级能力不同。每个工具都有自己的教程分组：

| 工具 | 教程 | 写入模式 | MCP | 技能 |
| --- | --- | --- | --- | --- |
| Claude Code | [配置 Claude](/zh/claude/configure) | 当前连接切换 | 支持 | 支持 |
| Claude Desktop | [配置 Claude](/zh/claude/configure) | 当前连接切换 | 不支持 | 不支持 |
| Codex | [配置 Codex](/zh/codex/configure) | 当前连接切换 | 支持 | 支持 |
| Grok Build | [配置 Grok Build](/zh/grok-build/configure) | 当前连接切换 | 支持 | 不支持 |
| OpenCode | [配置 OpenCode](/zh/opencode/configure) | 多连接共存 | 支持 | 支持 |
| OpenClaw | [配置 OpenClaw](/zh/openclaw/configure) | 多连接共存 | 不支持 | 不支持 |
| Hermes | [配置 Hermes](/zh/hermes/configure) | 多连接共存 | 支持 | 支持 |

“当前连接切换”表示工具的实时配置只指向一个当前连接；“多连接共存”表示 OcHub 会把多个连接
写入同一份工具配置，“从工具移除”只移除对应条目。

从 cc-switch 迁入现有配置时，先阅读[迁移教程](/zh/guides/migration)，了解同 ID 覆盖、备份
和分批验收。

涉及模型路由、数据库恢复或工具专属 JSON 时，请转到[高级功能](/zh/advanced)。
