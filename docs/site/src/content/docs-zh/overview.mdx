OcHub 是面向 AI 编程工具的原生桌面控制中心。切换服务商、管理共享能力、运行本地中转，
都在一个地方完成——不依赖浏览器外壳，也不用 webview。

## OcHub 管理什么

OcHub 管理 **Claude Code、Claude Desktop、Codex、OpenCode、OpenClaw 和 Hermes**。

| 领域 | 能力 |
| --- | --- |
| 服务商 | 发现、导入、编辑、切换和测试直连 API 服务商 |
| 中转站 | 让受支持的客户端经由本地网关路由，支持模型别名、推理映射、故障转移、健康检查和用量统计 |
| 共享工具 | 跨受支持客户端管理 MCP 服务器和可复用技能 |
| 运维 | 浏览会话、查看用量、配置同步、管理应用行为 |
| 迁移 | 从兼容的 cc-switch 数据库一次性只读导入 |

## 它如何触碰你的配置

OcHub 拥有 `~/.ochub/`，绝不回写 `~/.cc-switch/`。但它确实会更新你明确指定要管理的
那些工具的实时配置目录。

:::caution
在 OcHub 里切换服务商之前请先退出 cc-switch——两者写入同一批工具配置目录，同时运行
可能导致写入交错。
:::

:::note
OcHub 正处于活跃的预发布开发阶段。试用早期版本前请备份重要的工具配置。
:::
